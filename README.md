# STAR TO RECORD

追星記帳本：記買專輯小卡、預購代購、賣出，還有演唱會周邊的花費。
資料存在自己的 Google 試算表裡，手機優先，可以加到主畫面像 App 一樣開。

- **首頁** — 待處理：還沒付、還沒到貨、後補款還沒付、買家還沒匯款、還沒寄、待確認；
  預購（預計下個月以後才出貨）另外放「預購中」，不會一直催
- **記一筆** — 買單（多行品項、成員多選、多帶／重複／自留標記、各種費用）、賣單、花費
- **報表** — 花多少、收多少、每月長條圖、依團看（點進去看各回歸、各成員、**收集表**）、
  多帶花了多少、帳戶進出
- **明細** — 用月份框期間，依種類、團、成員、對象、帳戶、標記篩選，也能搜尋

右上角的眼睛按下去，金額都會變成 `$•••`。
外觀有淺色、深色、跟隨系統、粉紫，也可以**上傳自己的照片當背景**（只存在手機裡，不上傳）。

規格看 [需求規格.md](需求規格.md)。

## 第一次設定（三步）

### 1. 建一份 Google 試算表

隨便開一份新的試算表，名字自己取。分頁會在第一次連線時自動建好。

### 2. 部署後端

1. 在那份試算表裡：**擴充功能 → Apps Script**
2. 把 [google-apps-script/Code.gs](google-apps-script/Code.gs) 整份貼上
3. **把最上面的 `SECRET` 改成自己的一組密語**
4. 存檔 → **部署 → 新增部署作業 → 網頁應用程式**
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
5. 複製產生的網址（結尾是 `/exec`）

> 之後更新了 `Code.gs`，要**重新部署**（部署 → 管理部署作業 → 編輯 → 版本選「新版本」）。
> 設定頁最下面會顯示前端與後端版本。
>
> ⚠️ 改好密語的版本只貼在自己的 Apps Script 編輯器，**不要**貼回 GitHub。

### 3. 在 App 裡填進去

開啟 App → 右上角齒輪 → 貼上網址和**同一組**密語 → 儲存並測試。
右上角出現「已同步」就成功了。沒連線也能用，資料會先存在手機，連上之後自動補送。

手機上用 Safari 開，分享 → 加入主畫面。

## 開發

```bash
python3 scripts/serve.py 8790          # 本機伺服器，不走快取
node scripts/test-calc.js              # 計算邏輯測試（不用瀏覽器）
PW_CORE=<playwright-core 路徑> node scripts/screenshot.js     # 走流程＋截圖＋抓 console 錯誤
PW_CORE=<playwright-core 路徑> node scripts/test-layout.js    # 主題 × 頁面 × 寬度的版面掃描
node scripts/make-icons.js             # 重新產生圖示
```

改了 `www/` 裡的檔案，記得把 `www/sw.js` 的 `VERSION` +1。
測試資料一律虛構，不要放真實的買家、賣家、金額。
